본문 HTML 1개와 게임 HTML 여러 개를 한 번에 선택할 수 있어요. 예: K02.html, K02-G1.html, K02-G2.html
학교·이름이 붙은 제출용 본문·게임 파일도 다시 가져올 수 있어요. 다시 선택하면 같은 게임 번호의 파일을 교체해요. 파일을 가져온 뒤 미리보기를 완료하고 아래에서 제출을 준비해요.

표정·대사·사진과 장면 순서를 확인해요. 게임 장면은 가운데를 비우고 완료 상태로 넘겨요. 게임 파일이 없어도 미리볼 수 있으며, 게임 코드는 실행하지 않아요. 실제 체험에서는 게임을 풀어야 다음 장면으로 이동해요.
