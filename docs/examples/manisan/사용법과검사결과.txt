마니산에서 만난 삼각형의 비밀 — 완성 예시

파일
스토리보드.txt / 스토리보드.html / storyboard.json: 장면 구성, 게임 번호·연결 파일, 표정, 대사, 힌트
K02.html: 제작기에 가져올 스토리보드 본문
본문코드.txt: 같은 본문을 복사하여 붙여 넣을 때 사용
K02-G1.html: 독립 실행 게임. 두 문제의 정답은 10, 12
manisan-illustration.jpg: 사진1(IMG1)에 넣을 일러스트 배경
이미지프롬프트.txt: OpenAI 내장 image_gen으로 사용한 최종 프롬프트
mission.html: 제작기의 로컬 시험 업로드로 저장된 실행용 완성본
index.html: 완성본 체험과 스토리보드 표

사용법
1. https://jsh1065.github.io/incheon-mathtour/make.html 에서 K02 마니산 선택.
2. 탐구 주제: 피타고라스 정리로 산길의 길이 찾기.
3. 4단계에서 K02.html, K02-G1.html 두 파일을 함께 선택.
4. 사진1에서 manisan-illustration.jpg 선택.
5. 사진1 출처: OpenAI imagegen 생성 · 마니산을 모티브로 한 가상 일러스트 (2026-10-28).
6. 스토리보드 미리보기로 5개 장면을 확인. 게임 장면은 빈 공간이며 다음으로 이동 가능.
7. 학교·이름을 입력하고 마지막 미리보기 확인 완료 후 'GitHub에 업로드'를 누릅니다. 선생님이 나눠 준 공통 제작기는 제출코드가 미리 설정되어 있습니다.
8. 좌측 상단 '1. 스토리보드 작성'에서 현재 작품 또는 작성 양식을 선택해 TXT·HTML로 저장할 수 있습니다. 게임 장면의 게임 번호와 연결 파일명을 확인합니다. 메뉴 순서는 1. 스토리보드 작성 → 2. 미션 만들기 → 3. 체험하기입니다.

공개 업로드 버튼: 저장소 미연결 안내 확인. 실제 OneDrive 제출은 수행되지 않았음.
