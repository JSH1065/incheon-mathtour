나의 매스투어 작성 양식

K02 마니산 · 학교 미입력 · 이름 미입력본문: K02.html
  1. 관광지 소개 → 탐구 준비 → 게임 → 배운 수학 정리 순서로 이야기를 만들어요. 장면 수는 자유롭게 바꿀 수 있어요.
  2. 게임 장면에는 게임 1·게임 2처럼 게임 번호를 적어요. 게임 하나에 문제가 여러 개 있어도 같은 게임 번호를 써요.
  3. 본문에는 게임 번호만 연결하고, 게임은 각각 별도 HTML 파일로 만들어요. 사진은 IMG1·IMG2·IMG3와 출처로 연결해요.
  4. 게임에서는 정답 확인 후 다음 버튼을 활성화하고, 마지막 미션 완료 버튼에서 missionClear()를 호출해요.
  5. 스토리보드 미리보기에서는 게임 가운데가 비어 있고 바로 다음으로 넘어가요. 실제 체험에서는 게임 완료 후 다음 장면으로 이동해요.
